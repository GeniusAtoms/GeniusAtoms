# GeniusAtoms Profile Setup

1. Open `https://github.com/GeniusAtoms/GeniusAtoms`.
2. Upload `README.md` to the repository root.
3. Upload `assets/profile.png` into `assets/`.
4. Upload `.github/workflows/snake.yml` into `.github/workflows/`.
5. Commit the changes.
6. Open **Actions** and run **Generate Contribution Snake** once with **Run workflow**.
7. Refresh `https://github.com/GeniusAtoms`.

Krishna AI and Era-Assient currently have no public repository links, so no fake URLs are included.
